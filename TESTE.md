# Apagão: Ilha do Amparo — guia de teste

Obrigado por testar! O jogo ainda é um protótipo (gráficos de blocos e sons provisórios). O que importa agora é **jogar e contar onde travou, onde se perdeu e o que foi chato ou legal**.

## Como abrir

**Windows:** extraia o .zip e abra `Apagao.exe`. Se o Windows avisar ("O Windows protegeu o computador"), clique em **Mais informações → Executar assim mesmo**.

**Linux:** extraia o .zip e, no terminal, dentro da pasta:

```bash
chmod +x Apagao.x86_64
./Apagao.x86_64
```

## Controles

| Tecla | Ação |
| --- | --- |
| WASD | Andar |
| Shift | Correr |
| C ou Ctrl | Agachar |
| Espaço | Pular · de frente para uma borda: escalar |
| Alt | Esquivar |
| Mouse | Câmera · botão direito: mirar · esquerdo: atacar/atirar |
| 1 / 2 / 3 / 4 | Facão / Revólver / Espingarda / PEM (quando você já tiver) |
| R | Recarregar |
| Segurar E | Pegar itens, sabotar antenas, usar coisas · por trás de um robô: takedown |
| Segurar Tab + número | Fabricar |
| T / segurar G | Escolher / arremessar |
| H | Kit de primeiros socorros |
| Esc | Pausa (opções de volume e sensibilidade) |

O losango amarelo e a bússola no topo mostram para onde ir. Morrer volta ao último checkpoint.

## O que anotar

Para cada coisa, diga **em que ato** estava (aparece na tela quando muda) e, se der, mande um print.

1. **Onde você se perdeu** ou não entendeu o que fazer.
2. **Onde morreu** e se a morte pareceu justa.
3. **Bugs:** atravessou parede, inimigo travado, objetivo que não completa, travamento.
4. **Quanto tempo** levou cada ato (mais ou menos).
5. **O que foi mais legal e o que foi mais chato.**
6. Seu computador (Windows ou Linux, e se o jogo ficou lento).

Mande tudo para o Vinícius. Valeu!
